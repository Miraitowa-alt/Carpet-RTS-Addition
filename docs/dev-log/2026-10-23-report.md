## 二、关键决策与依据

| 决策 | 依据 |
|---|---|
| 不采用 AMS 的自定义 `@Rule` + 反射注册器，改用 Carpet 原生 `carpet.api.settings.Rule` | 26.3 原生注解已具备 `categories/options/strict/validators`；AMS 的反射是为兼容 MC < 1.19.4，且反射的是私有内部构造器（运行时失效风险） |
| 不加多版本预处理器 | 项目只有 26.3 一个目标版本 |
| 配方开关用"查询层过滤"而非"加载期过滤" | 注册表运行时不可增删；查询层过滤可以即时生效（代价：配方书 display 残留） |
| 加 Fabric API 依赖 | 实测无 `fabric-resource-loader-v0` 时 `/datapack list` 只有 vanilla，配方全部静默不加载 |
| 桶的注入返回 `copy()` | `ItemUtils.createFilledResult` 会 `consume()` 原栈，返回同一实例会导致物品消失（已实测复现） |
| 附魔身份不缓存实例 | `/reload` 会重建附魔注册表，缓存的旧实例失效 |

## 三、踩坑与修复（可复用的经验）

1. **PowerShell 写文件带 BOM** → access widener 头解析失败；必须无 BOM 写入。
2. **access widener 命名空间**：26.x 必须写 `classTweaker v1 official`（`named` 会被 Loom 拒绝）。
3. **配方目录**：`data/<ns>/recipe/`（单数）；标签写 `"#tag"` 字符串。
4. **缺 Fabric API 时模组数据静默不加载**，排查看 `/datapack list`。
5. **`createFilledResult` 消耗返回实例** → 必须 `copy()`；且**创造模式会掩盖该 bug**，要用生存模式测。
6. **规则名需要 `.name` 键**，否则中文下显示裸 ID；Carpet 有翻译时会显示成 `中文名 (ID)`。
7. **翻译键前缀 = SettingsManager 的 identifier**（当前是 `carpet.`），迁移 manager 必须同步改键。
8. **用 `Get-Content -Raw` 读写非 ASCII 文件会乱码**（默认 ANSI），需显式 UTF-8。
9. **提交尾注**：`Co-authored-by` 会让协作者出现在 GitHub Contributors，已重写历史清除。
